.. warning::
   Deprecated Encryption Algorithms for PDF Files

   When working with PDF files using the `ibm_watsonx_ai` package, attempting to use
   outdated encryption algorithms, such as ARC4, requires explicitly clearing or
   disabling the environment variable ``CRYPTOGRAPHY_OPENSSL_NO_LEGACY`` before importing
   the package. To clear the variable, use the following Python code snippet:

   .. code-block:: python

      import os
      del os.environ['CRYPTOGRAPHY_OPENSSL_NO_LEGACY']

   Failure to do so will prevent the usage of these algorithms when reading PDF files.
   Please be aware that support for these legacy algorithms is being phased out, and their
   continued usage is at the user's discretion and risk.
