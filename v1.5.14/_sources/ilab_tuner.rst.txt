###############################
 InstructLab Experiment (BETA)
###############################

Using TuneExperiment, special InstructLab tuner can be created. The tuner is similar to fine tuner and prompt tuner in
usage. InstructLab fine tuning is available only with IBM watsonx.ai for IBM Cloud.

.. note::

    InstructLab fine tuning is in currently in closed beta stage. Feature available only for whitelisted users. Breaking
    changes in API may be introduced in the future.
