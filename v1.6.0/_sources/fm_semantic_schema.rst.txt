*******************
 Schema Operations
*******************

The ``SemanticSchema`` class provides access to four specialized operation classes through its attributes:

- ``create`` - Create new schemas from documents
- ``improve`` - Improve existing schemas
- ``merge`` - Merge multiple schemas into one
- ``cluster`` - Cluster similar schemas
